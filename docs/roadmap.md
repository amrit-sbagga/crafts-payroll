# Product Roadmap

## Vision

Build a modern HR salary intelligence platform that helps organizations manage employee compensation, payroll visibility, and workforce analytics at scale.

---

# Current MVP (Completed)

Implemented features:

## Employee Management
- Add / Edit / Delete employees
- Search / sort / filter
- Pagination
- Employee profile page

## Analytics Dashboard
- Country salary metrics
- Department analytics
- Job title insights
- Salary distribution charts
- KPI summary cards

## User Experience
- Responsive UI
- Light / Dark / System themes
- Settings menu
- Export reports

## Platform
- PostgreSQL + Prisma
- 10,000 employee seed support
- Modular frontend architecture

# Prioritization Philosophy

The roadmap prioritizes:

1. Core payroll workflows first
2. HR decision-making intelligence second
3. Enterprise security and scale third
4. AI automation after operational maturity

# Notes

This roadmap reflects possible future evolution and was intentionally scoped separately from the take-home MVP.
